# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.4.x   | :white_check_mark: |
| < 0.4   | :x:                |

## Reporting a Vulnerability

To report a security vulnerability, please open a private vulnerability report at:

https://github.com/nagusubra/timeseries-qc/security/advisories/new

You can expect an acknowledgement within 48 hours and a detailed response within 5 business days. Please do not report security vulnerabilities through public GitHub issues.

## Security Practices

- **Dependabot**: Automated dependency updates are enabled. Pull requests are reviewed and merged regularly.
- **Secret Scanning**: GitHub secret scanning is enabled with push protection.
- **Code Review**: All changes to `main` require an approved pull request with passing CI checks.
- **Actions Permissions**: GitHub Actions are restricted to verified GitHub-owned actions only.
